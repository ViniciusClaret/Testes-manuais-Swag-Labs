# Testes-manuais-Swag-Labs


# Testes manuais - Swag Labs #


## Objetivo #
O maior objetivo do projeto além da experiência prática é criar e executar manualmente as suítes de login e carrinho, concluir os casos de teste para validação dos dois fluxos, validar os caminhos felizes, definir prioridades, registrar evidências e detectar falhas. Este projeto também marca o início do meu portfólio.

## Ambiente de teste ##
**URL testada:** https://www.saucedemo.com/<br>
**Navegador:** Google Chrome (versão 154.0.8037.93)<br>
**Dispositivo:** Desktop (1920x1080)<br>
**Ferramentas utilizadas:** Testes manuais, GitHub (versionar fases)<br>

## Estrutura do repositório ## 

As pastas `01-login` e `02-carrinho` reúnem a documentação dos casos de teste manuais, com:

- validações realizadas e resultados obtidos;
- prováveis bugs encontrados;
- quantidade de casos de teste;
- autoria dos testes;
- ambiente utilizado e versão;
- critérios adotados.

A pasta de `Evidências` reúne os registros que comprovam a execução dos testes nao aprovados, como prints e/ou vídeos dos resultados e dos bugs encontrados.


## Resultado da execução ##
Totalizando 44 testes e apenas 1 reprovado (evidencia )
